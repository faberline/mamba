## Scope

Original tools run only for development acceptance. Fixture programs are input
data. The capture helpers do not execute their bodies. Local checks use static
readers and mocked helper controls. Original tools run on GitHub runners.

Process exits apply to complete commands. API results are separate from process
exits. Formatter bytes, source input selection and context-specific errors keep
their original comparison boundaries.

compatibility, SOM, release or #15 acceptance. The 412 native obligations remain
