> - Commands using `git status --porcelain=v1 -uall`, `git diff --name-status`, `git ls-tree -r --name-only`, or `git ls-files --others --exclude-standard` verify **file names, status codes, and file counts only**; they do **not** verify byte contents of untracked files or compare working-tree bytes against external JSON manifests.
