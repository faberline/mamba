# Product capabilities

The [product requirements index](../product/README.md) owns the capability list and its status links. This page is a route into that list. It does not add a promise.

## Project workflow

The [package manager requirements](../product/package-manager.md) describe project setup, environment creation, dependency locking, sync, and run. The [project README](../../README.md) shows the command sequence.

## Python kits

The [mambalibs requirements](../product/mambalibs.md) describe CPython wheels and the later runtime carrier. The [integration guide](../integration/native-runtime-integration.md) defines the native binding contract.

## Compiler and runtime

The [runtime requirements](../product/runtime.md) describe the CPython runtime replacement outcome. The [project README](../../README.md) orders its tiers and states that their exit gates are still to be written. The [source map](../../llms.txt) lists compiler and runtime modules and separates self-written fixtures from the pending external conformance denominator.

Read [STATUS.md](../../STATUS.md) for measured shipped scope and [ROADMAP.md](../../ROADMAP.md) for future outcomes. Do not infer full tool or platform parity from this index.
